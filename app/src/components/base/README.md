分類の基準
1. forms/ - フォーム関連
用途: ユーザー入力を受け取るコンポーネント
Input, Textarea, Select, Checkbox, RadioGroup, FileInput

2. feedback/ - フィードバック系
用途: ユーザーに状態や結果を伝える
Alert, Toast, Spinner, ProgressBar, Skeleton

3. actions/ - アクション系
用途: ページ遷移やアクションを促す
Button, Link, Breadcrumb, Pagination, Tabs

5. overlay/ - オーバーレイ系
用途: 元の画面の上に重ねて表示するもの
Modal, Loading, Banner, Tooltips

6. layout/ - レイアウト
用途: 画面レイアウトに関わるデータや情報の見せ方を決める部品
Container, Grid, Flex, Divider, Table, Card, Badge, Avatar
